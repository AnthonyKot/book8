# Episode transcripts

Machine transcripts of each generated episode, used to check the audio against the chapter before embedding. Made with faster-whisper (small model, audio split at silence and run in parallel), so proper nouns are unreliable: Qing reads as "king", Adwa as "Ottawa", Amartya Sen as "a martyr sin". Never treat a mangled name here as a defect in the audio without listening first. Wording of ordinary prose is accurate.

`<slug>.txt` is the readable transcript. `<slug>.timed.txt` carries per-segment timestamps, for jumping to a moment in the episode.
