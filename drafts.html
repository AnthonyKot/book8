Provenance

This page was the drafting workbench. The chapters now live in the book proper; everything that used to be here — parallel drafts from three writers, pitch banks, merge rounds, review files — is preserved in the repository's git history rather than on the site.

Pipeline per chapter, for the record: topic dossier from the corpus → three-writer draft matrix → editor audit (every quote grep-verified against both the translated and the original-language corpus, banned-word sweep) → reader pitch pick → thread drafted → merge → literary critique (sliding three-chapter window) → essay-mode rework → de-instrumentation pass. The reader chose the threads; the receipts kept everyone honest.
